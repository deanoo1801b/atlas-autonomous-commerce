# KKAM BOOKS — Ranked n8n Workflow Shortlist

**Research date:** 2026-10-12  
**Ranking basis:** relevance to KKAM PDF/illustration factory, graph integrity, placeholder count, credential/paid-service burden, and external side effects. The complete static scan parsed 2,061 JSON files. It found 1,363 files with unresolved connection references, and the sample candidates below contain connections pointing to generated `error-handler-...` targets absent from their node lists. This means they are **not approved for direct import**; the ranking is for reusable node patterns only. Workflows were not imported or executed. Repository/per-file metadata says MIT, but third-party assets/services still require separate review.

**Search terms used across filenames, node names, notes and parameters:** PDF, HTML to PDF, Markdown to PDF, DOCX, document generation, report generation, merge PDF, split PDF, PDF metadata, Read PDF, Extract from File, Convert to File, image generation, image editing, line art, black and white, background removal, resize, upscale, image processing, image metadata, content generation, story, worksheet, prompt, template, Google Drive, Google Sheets, Airtable, OneDrive, Shopify, database, listing, SEO, publish, social media, schedule, cron, error, approval, human review, retry, wait, execute workflow and webhook.

## Critical graph-integrity finding\n\nThe full static scan counted 27,524 unresolved connection targets plus 3 unmatched source keys across the current collection; 1,360 files use node IDs as connection-map source keys instead of node names. In each of the five highest-ranked candidates inspected in depth, every counted connection target was unresolved by the static graph check. This may reflect a transformed or synthetic export format, but it is not evidence of a valid n8n import. Before using any workflow, compare it with a native export from the target n8n version and rebuild its connections by node name. The safe default is to reimplement the useful node sequence in a fresh workflow.\n\n## Licensing, cost and security policy

- Do not expose or reuse the credential IDs/names found in sample exports. Create new credentials in the user's own n8n instance.
- No direct-import recommendation is currently approved. The strongest approach is a small custom PDF engine plus carefully adapted isolated node patterns.
