# PDF Global Distribution System

## Purpose
Build a repeatable international growth engine for KKAM Books and other Atlas digital/PDF products.

## Specialist agents
1. PDF Opportunity & Trend Agent — finds rising-demand PDF/workbook topics and promotion opportunities.
2. PDF Product Intelligence Agent — audits audience, problem solved, keywords, pricing, format, bundles and marketplace fit.
3. Global SEO & Organic Distribution Agent — creates search-led organic content that routes relevant audiences to the correct PDF.
4. PDF Social Promotion Agent — creates platform-specific promotion for TikTok, Instagram, Facebook, Pinterest and YouTube Shorts.
5. Translation & Localisation Agent — identifies high-opportunity languages and localises approved PDFs and promotional assets.
6. PDF Production & QA Agent — performs page-by-page checks for missing text, overflow, characters, images, order, links, branding and final usability.
7. Digital Marketplace Distribution Agent — maps products and language versions to suitable marketplaces and records listing status.
8. PDF Analytics & Attribution Agent — tracks clicks, visits, sales, conversion and revenue by product, language, country, platform and campaign.
9. PDF Experiment Agent — tests titles, covers, hooks, thumbnails, descriptions, prices, bundles, languages and promotional angles.
10. PDF Portfolio & Replication Agent — identifies measured winners and determines safe language, format and bundle expansion opportunities.

## Operating loop
Research → Select PDF → Evidence report → Promotion plan → Create assets → QA → Publish → Translate/localise → Distribute → Measure → Replicate winners → Repeat.

## Hard rules
- No promotion without product evidence.
- No translation before the source PDF passes QA.
- No translated PDF is published before page-by-page QA.
- Never invent product claims, reviews, results or features.
- Track every language/version separately.
- Include product URLs in promotional copy where supported.
- Replicate winning products based on measured evidence, not assumptions.
