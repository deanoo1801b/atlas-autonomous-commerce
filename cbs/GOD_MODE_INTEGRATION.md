# CBS / ATLAS God Mode Integration

ATLAS remains the master autonomous-commerce controller. CBS is a specialist publishing factory under ATLAS rather than a separate master agent.

ATLAS controls: priorities, permissions, approval gates, budgets, audit events, agent health and cross-business resource allocation.

CBS controls: coloring-book opportunity research, competitor-gap analysis, original concept development, production specifications, QA, KDP packaging, Shopify digital-product preparation and publishing-performance feedback.

Escalation path:
CBS evidence → CBS opportunity score → ATLAS decision gate → approved production → QA → human approval → publishing → performance → learning.

No CBS agent may bypass ATLAS approval controls for publishing, paid advertising, irreversible catalogue changes or external-account actions.
