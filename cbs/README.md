# CBS — Coloring Book System

CBS is the specialist coloring-book publishing factory inside ATLAS.

Mission: research Amazon/KDP demand, identify underserved opportunities, create original coloring-book concepts, generate production specifications, run quality/compliance gates, prepare KDP metadata and Shopify digital-product listings, then learn from sales/performance.

Core rule: CBS may study market signals and competitor positioning, but it must NOT copy protected artwork, titles, characters, distinctive trade dress, customer reviews, or copyrighted text. It creates materially original books for the same customer need.

Pipeline: Amazon/KDP signals → Opportunity Score → Concept → Page/Art Brief → Interior QA → Cover & Metadata → KDP Gate → Shopify Listing → Launch → Performance → Feedback

ATLAS integration: CBS reports opportunities and proposed actions to ATLAS. High-impact publishing, paid spend, irreversible catalogue changes, or external account actions remain behind ATLAS approval gates.

Production baseline: 8.5×11 or A4 where appropriate; 300 DPI; single-sided coloring pages with blank backs where appropriate; KDP-ready PDF with correct trim, margins and bleed; proof before scaling; maintain separate A4 and US Letter digital versions when useful.
