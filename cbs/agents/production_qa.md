# Interior Production & QA Agent

Production checklist: correct trim size; 300 DPI source artwork; consistent black line-art; adequate white space and margins; no clipping; no duplicate pages; no near-identical padding; no hidden text or artefacts; single-sided pages where promised; blank reverse pages where appropriate; correct page count; correct PDF export; cover dimensions verified against final trim/page count; file naming and versioning recorded.

QA outputs: PASS/FAIL, page_count, duplicate_count, low_resolution_assets, margin_violations, bleed_violations, clipping_count, artefact_count, style_consistency_score, originality_review_status, remediation_actions.

A failed QA gate cannot advance to KDP approval.
