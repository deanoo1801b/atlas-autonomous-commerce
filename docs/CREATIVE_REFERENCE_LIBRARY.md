# ATLAS Creative Reference — Checklist / Systemized-Outcome Ad Pattern

**Added:** 2026-10-02  
**Source:** User-supplied social ad screenshot  
**Status:** Approved as a creative-reference pattern, not a template to copy.

## What the reference demonstrates

The reference uses a vertical social-ad structure built around a strong, outcome-oriented headline followed by a simple visual checklist:

1. Large, high-contrast hook.
2. A short sequence showing how the system works.
3. Progressive completion/checklist framing.
4. A clear benefit/outcome.
5. One obvious CTA.
6. Minimal supporting copy so the message can be understood quickly on mobile.

The reference also uses an AI-generated visual style and a platform-native social-ad presentation.

## ATLAS adaptation

ATLAS may use this **format logic** for original creative:

**Hook → Problem → Simple steps → Product/value → CTA**

Examples of ATLAS-safe hooks:
- “3 things that make this job easier”
- “Before you buy one, check these 3 things”
- “A simple way to organise this”
- “Watch how this works”
- “One small upgrade for everyday life”

For product creative, the checklist can become:
- What problem it addresses
- What the product visibly does
- What is included, where verified
- How to use it
- Clear product CTA

## Hard rules

- Do not copy the reference's wording, layout, branding, creator identity, imagery, or distinctive creative execution.
- Use the reference only for structural inspiration.
- Do not invent product features, specifications, reviews, results, guarantees, scarcity, discounts, or customer outcomes.
- Product claims must be supported by the live Shopify product data or another reliable product source.
- Use the exact product identity and current price/availability where relevant.
- Include the correct Atlas product URL in promotional copy.
- AI-generated content must use the applicable platform AI-content disclosure fields when publishing.
- Run the ATLAS Compliance & Brand QA Agent before publication.
- Public publishing remains approval-gated.

## Testing framework

When this pattern is used, test one primary variable at a time where practical:
- Hook wording
- Checklist structure
- Opening visual
- Demonstration angle
- CTA wording

Track:
- 3-second/early retention where available
- video completion
- saves/shares/comments
- profile visits
- product-page clicks
- add-to-cart
- checkout
- completed purchase

Do not call a creative a winner without sufficient measured evidence.
