# Catalogue Cross-Reference Gate

Before any product is recommended, the system must compare it with the current Atlas Goods Store catalogue. Match on product ID, SKU, handle and normalized title. Exact matches are blocked; highly similar titles are held for human review. Only unmatched products proceed to demand, trend, margin and content scoring. The catalogue snapshot timestamp and source must be recorded. This gate controls recommendation eligibility only and does not create, publish, purchase or modify products automatically.
