# ATLAS Agent Coordinator

The coordinator is the routing layer between opportunity intelligence and specialist execution.

## Routing

Opportunity Report
→ evidence check
→ specialist route
→ controlled task
→ experiment/result capture
→ scale or return to research.

Supported routes include:

- Research / watch
- Digital product
- Shopify
- SEO / global sales
- Social media
- Video
- Creative / image
- Experimentation
- Scale
- Reject

## Evidence discipline

Opportunity reports explicitly separate facts from assumptions. A trend signal is not treated as proof of demand. Low-confidence or weak-evidence opportunities return to research.

## Scale gate

A report is not scale-ready simply because it has a high trend score. ATLAS requires a validation test, measurable scale criteria, documented risks and sufficient confidence. Scaling remains approval-gated.

## Operating principle

The coordinator routes work; it does not bypass the commercial publishing gate.
