# ATLAS Seven-Day Reels Testing Template

Use this as a rolling test plan. Fill from current audience, inventory, analytics and demand evidence before choosing products or making performance claims.

| Day | Test focus | Hypothesis | Main variable | Primary metric | Required output |
|---|---|---|---|---|---|
| 1 | Problem-led hook | A clearly named audience problem earns more qualified attention | Opening hook | Average watch time or retention, if available | Reel script + baseline |
| 2 | Demo-first opening | Showing the action immediately improves early retention | Opening visual | 3-second hold/retention, if available | Shot list + script |
| 3 | Practical checklist | A useful checklist increases saves | Value structure | Saves per reach | Reel or carousel adaptation |
| 4 | Common mistake | A specific mistake creates relevant curiosity | Topic angle | Average watch time and shares | Script + evidence |
| 5 | Quick comparison | A fair, substantiated comparison improves understanding | Explanation format | Saves and qualified comments | Comparison script |
| 6 | Question-led content | Answering a real audience question drives relevant engagement | Hook format | Shares, comments and profile actions | Q&A Reel |
| 7 | Best evidence-backed concept | Refining the strongest signal improves the next test | One chosen element | Primary metric for the hypothesis | Review and next-week decision |

## Before the week
- Verify account/platform data available.
- Choose audience questions from evidence, not assumptions.
- Verify product URL and stock if a product is featured.
- Record baseline and hypothesis.
- Prepare original assets and compliance review.
- Obtain publication approval.

## After each post
Record publish time, platform, concept ID, hook, duration, reach/plays, watch-time/retention where available, saves, shares, comments, profile actions, link clicks, product sessions and conversions where attributable.

## Weekly review
1. What is directly supported by the data?
2. What is only a hypothesis?
3. Which concepts deserve another test?
4. Which should be revised or stopped?
5. What three changes take priority next week?

Never call a Reel a sales winner based on views or likes alone.
