# ATLAS Architecture

## Master controller

**ATLAS** coordinates specialist agents, enforces permissions, records decisions and evaluates outcomes.

## Agent lifecycle

1. Define objective
2. Give minimum required permissions
3. Give bounded resources
4. Run task
5. Record inputs, actions and outputs
6. Measure commercial outcome
7. Continue, revise or retire

## Permission tiers

### Tier 0 — Observe
Read-only data access and analysis.

### Tier 1 — Recommend
Generate proposed actions but do not execute consequential changes.

### Tier 2 — Controlled write
Execute narrowly scoped actions within explicit limits.

### Tier 3 — Autonomous optimisation
Only enabled after measurable performance and safety criteria are met.

No agent receives unrestricted access by default.

## Commerce data flow

Shopify → Analytics → Opportunity Detection → Product/Content Experiments → Traffic → Orders → Profit Measurement → Learning

## Agent replication

ATLAS may propose a new specialist when an identifiable workload is repeatedly measurable and separable. New agents must receive a defined purpose, resource budget, permissions and success criteria before activation.
